# Ben Oz Digital Gallery Documentation

This directory documents the creative intent, current implementation, content model, and working practices of the Ben Oz Digital Gallery.

Start with [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) for the authoritative project background and [VISION.md](VISION.md) for the principles that should guide decisions.

## Documentation index

- [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) — canonical project identity, content facts, media relationships, and current priorities.
- [VISION.md](VISION.md) — creative philosophy and long-term direction.
- [ROADMAP.md](ROADMAP.md) — current status and staged path toward Release 1.0 and beyond.
- [ARCHITECTURE.md](ARCHITECTURE.md) — current React/Vite structure, data flow, interaction ownership, and assets.
- [CONTENT_MODEL.md](CONTENT_MODEL.md) — Collections, Works, Songs, IDs, relationships, and media conventions.
- [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) — visual tokens, layout principles, interaction restraint, mobile, and accessibility.
- [GOOGLE_SHEETS.md](GOOGLE_SHEETS.md) — spreadsheet schema, synchronization flow, validation expectations, and fallback behavior.
- [DEPLOYMENT.md](DEPLOYMENT.md) — local commands, production build, Netlify guidance, and release checks.
- [CONTRIBUTING.md](CONTRIBUTING.md) — repository workflow, coding conventions, review expectations, and verification.
- [CHANGELOG.md](CHANGELOG.md) — project release history in a format intended for future entries.

## Source of truth

Documentation explains the repository but does not override approved creative or content decisions. When documents conflict, use this order:

1. Explicit task instructions and approved content decisions.
2. `AGENTS.md`.
3. [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md).
4. The current implementation and the remaining documents in this directory.

Keep current behavior and future plans clearly separated when updating these files.
